# Applied AI Engineering Bootcamp

This repository documents my 8-week transition from a Software Engineer to an AI-Native Engineer, focusing on building production-grade Agentic Systems using FastAPI and the latest LLM models.

## 🚀 The Roadmap

- **Week 1: Structured Outputs** (Current) - Moving from text to validated JSON.
- **Week 2: Function Calling** - Giving agents the ability to use tools.
- **Week 3 & 4: RAG & Vector DBs** - Giving agents memory and knowledge.
- **Week 5 & 6: Orchestration & Multi-Agent** - Building complex autonomous workflows.
- **Week 7 & 8: Observability & Production** - Evaluating and securing AI systems.

## 🛠 Tech Stack
- **Backend:** Python, FastAPI
- **AI Models:** OpenAI GPT-4o / GPT-5, Claude 4
- **Tools:** Pydantic (Validation), LangGraph (Orchestration), ChromaDB (Vector Search)
